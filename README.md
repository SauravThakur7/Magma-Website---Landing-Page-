This project is a business based landing page, whose inspiration is taken from an official website: https://thisismagma.com/

I've used HTML , CSS and Js to create this, also few other libraries have been used to add smooth scrolling in this like locomotive and scroll Trigger for smooth scrolling effect and for rich UI/UX.
